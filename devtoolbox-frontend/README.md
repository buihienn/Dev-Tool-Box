# DevToolBox frontend

This React application provides the DevToolBox interface, including dynamic tool pages, search, favorites, authentication, premium access, and administration screens.

For prerequisites, environment configuration, local startup steps, testing, and plugin guidance, see the [project README](../README.md).

Quick start:

```powershell
Copy-Item .env.example .env.local
npm install
npm start
```

The development server opens at `http://localhost:3000` and uses `REACT_APP_API_BASE_URL` for backend requests.
